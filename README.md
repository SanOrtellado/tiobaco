# Tío Baco — Landing page

Landing page para **Tío Baco · Vinos y Experiencias** (Belgrano 502, Coronel Pringles, Buenos Aires).
Trabajo práctico de diseño: brandbook aplicado a una landing responsive de una sola página.

## Ver online

Publicado con GitHub Pages: https://sanortellado.github.io/tiobaco/

## Contenido

- `index.html` — la página publicada. Archivo único autocontenido (imágenes y estilos incluidos), no necesita servidor ni dependencias.
- `src/` — archivos fuente del diseño.
  - `Tio Baco Landing.dc.html` — el diseño editable.
  - `support.js` — runtime necesario para abrir el archivo fuente.
  - `extracted/` — fotos usadas en la página.

## Secciones

Hero · Historia · Experiencias · Eventos del mes · Carta de vinos · Instagram · Visitanos

## Funcionalidad

- Diseño responsive (mobile, tablet y desktop).
- Formulario de reserva que arma el mensaje y lo envía por WhatsApp.
- Mapa de Google embebido con la ubicación del local.
- Enlaces a Instagram (@tiobaco) y WhatsApp de reservas.

## Publicar cambios

1. Editar `src/Tio Baco Landing.dc.html`.
2. Regenerar `index.html` como archivo único.
3. Commit y push a `main` — GitHub Pages actualiza solo.
